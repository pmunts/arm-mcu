Introduction

This crate provides an object oriented I/O library for the RP2040 ARM 32-bit microcontroller, layered upon the GNAT Predefined Embedded Runtime implemented by the embedded_rp2040 and rp2040_hal crates and their dependencies. It is intended to be a optional but very useful add-on to the munts_rp2040_firmware_embedded firmware image builder crate.

Usage Example

alire-rp2040-embedded-newproject myfirmware
cd myfirmware
alr -n with munts_rp2040_lib_embedded
alr build

The project creator shell script alire-rp2040-embedded-newproject and its subordinate project renaming shell script alire-rename are available at:
https://github.com/pmunts/alire-goodies.

These scripts are also provided by the alire-goodies Debian package available at:
https://repo.munts.com/debian13/all.
