# RP2040 ARM Microcontroller Specific Ada Packages

These are [RP2040 MCU](https://www.raspberrypi.com/products/rp2040/)
hardware specific packages. Many of them are inspired by packages in the
[Linux Simple I/O Library](https://github.com/pmunts/libsimpleio) Ada
binding package library.

See [Alire](https://alire.ada.dev) crate
[munts_rp2040_lib_embedded](https://alire.ada.dev/crates/munts_rp2040_lib_embedded.html)
for more information.
