# Hardware Independent ARM Microcontroller Ada Packages

These are MCU independent device driver and abstract interface packages
for ARM microcontrollers. Many of them are adapted from or at least
inspired by packages in the [Linux Simple I/O
Library](https://github.com/pmunts/libsimpleio) Ada binding package
library.

See [Alire](https://alire.ada.dev) crate
[munts_rp2040_lib_embedded](https://alire.ada.dev/crates/munts_rp2040_lib_embedded.html)
for more information.
